# CS312-Project2
## Background
### Purpose
The purpose of this GitHub Repo is to provide a fully automated creation of a Minecraft Server (provisioning, configuration, and setting up the Minecraft Server). 

### How It Works
After cloning  accessing the folder  running the 'install.sh' bash script, it will run the other scripts 


## Requirements
- Linux Environment or WSL
- AWS CLI
- Terraform
- Nmap


### Installing the Requirements
Open the Command Line Interface Command Prompt for Windows and Terminal for Linux users.

## Installing WSL
`wsl --install`
`wsl --version`

## Installing AWS CLI

In WSL:
```
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
```
